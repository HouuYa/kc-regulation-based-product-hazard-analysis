# 모듈 색인 (자동 생성)

`npm run docs:index` 로 다시 만든다 — **손으로 고치지 않는다.** 설명이 틀렸거나 비어 있으면 그 파일의 머리 주석을 고치고 다시 만든다. 개념 단위 지도(어떤 일을 어느 코드가 맡는가)는 [기능 지도](기능_지도.md)에 있다.
