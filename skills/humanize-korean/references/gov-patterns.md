# gov-patterns.md — 정부·행정 문서 특화 패턴 (K 카테고리)

> **적용 범위**: 정부보고서·정책문서·공문·기획서·예산서·심의자료
> **추가 배경**: 행정 공문서에서 AI가 생성한 개조식 명사화 어미(`됨/함/임`)·
>   판단·추진·검토 표현이 번역투와 결합하여 AI 티를 강하게 노출함
> **핵심 원칙**: 한국 공문서 개조식은 `동사 → 명사화`가 원래 표준이나,
>   AI가 생성 시 불필요한 수식어·완곡어와 결합하여 과잉 명사화됨.
>   이 파일은 그 패턴만 탐지·교정함.

---

## K-1 명사화 피동 결말 `~됨 / ~함 / ~임` 불필요 수식 결합 [S1]

**신호**: 개조식 서술에서 명사화 어미 앞에 `것으로 판단됨`, `것으로 보임`처럼
  판단·추측 완곡어가 결합하여 이중 축약 발생

**탐지 패턴 → 처방:**

| 원문 패턴 | 처방 | 비고 |
|-----------|------|------|
| `~할 것으로 판단됨` | `~로 판단` | 과거·현재형 모두 적용 |
| `~할 것으로 판단됩니다` | `~로 판단함` (개조식) 또는 `~로 판단합니다` (서술식) | |
| `~인 것으로 파악됨` | `~로 파악` | |
| `~인 것으로 확인됨` | `~로 확인` | |
| `~할 것으로 사료됨` | `~로 판단` | `사료됨`은 과도한 격식 표현 |

## K-2 추진·계획 표현 과잉 명사화 [S1]

**신호**: `~에 따라 추진할 예정임` 처럼 추진 의지 표현에 수식 과잉

**탐지 패턴 → 처방:**

| 원문 패턴 | 처방 |
|-----------|------|
| `~에 따라 추진할 예정임` | `~추진 예정` |
| `~를 추진할 계획임` | `~추진 계획` |
| `~를 시행할 예정에 있음` | `~시행 예정` |
| `~를 검토할 계획을 가지고 있음` | `~검토 예정` |
| `~을 추진해 나갈 예정임` | `~추진 예정` |
| `~를 지속적으로 추진해 나갈 방침임` | `~지속 추진` |
| `~를 추진해 나가도록 할 예정임` | `~추진 예정` |

## K-3 필요성·대두 표현 과잉 [S1]

**신호**: 필요성을 제기하면서 이중 수식으로 강도를 희석

**탐지 패턴 → 처방:**

| 원문 패턴 | 처방 |
|-----------|------|
| `~에 대한 필요성이 대두되고 있음` | `~필요성 대두` |
| `~의 필요성이 점점 높아지고 있음` | `~필요성 증가` |
| `~에 대한 중요성이 강조되고 있는 상황임` | `~중요성 부각` |
| `~의 필요성이 제기되고 있는 실정임` | `~필요성 대두` |
| `~에 대한 관심이 높아지고 있는 추세임` | `~관심 증가` |

## K-5 현황·상황 어미 과잉 [S2]

**신호**: `~하고 있는 실정임`, `~인 상황임` 등 AI가 생성한 공문체 강조 상황어

**탐지 패턴 → 처방:**

| 원문 패턴 | 처방 |
|-----------|------|
| `~하고 있는 실정임` | `~중` 또는 직접 서술 |
| `~인 상황에 놓여 있음` | `~상황` |
| `~에 어려움을 겪고 있는 상황임` | `~어려움 발생` |
| `~하고 있는 추세를 보이고 있음` | `~추세` |
| `~한 문제점이 발생하고 있음` | `~문제 발생` |

**신호**: 서술식 공문에서 불필요한 이중 완곡

**탐지 패턴 → 처방:**

|-----------|------|

## 정부 문서 장르 판정 기준

다음 신호 중 2개 이상 감지 시 자동으로 gov-patterns.md 적용:
- `추진 예정 / 추진 계획`이 2회 이상
- `부처명 / 과명` 등장 (예: 기재부, 산업부, 국기원 등)
- `「법령명」` 형식 (꺾쇠 괄호 법령 인용)
- `예산`, `백만원`, `억원`, `기금` 등 예산 어휘
- `~임`, `~함`, `~됨`으로 끝나는 문장이 전체 50% 이상
- 제목에 `계획`, `방안`, `대책`, `추진`, `현황` 포함

## 정부 문서 개조식 유지 원칙

**건드리지 않는 패턴** (정부 문서 표준):
- `○ ~를 추진함` — 단순 개조식 명사화. 수식 없으면 유지
- `- 검토 결과 → 적합` — 결과 서술 단순 명사화. 유지
- `※ ~에 따라 시행 예정` — 근거 명시 있는 단순 추진 표현. 유지

**교정 대상**은 오직: 위 K-1~K-8에서 탐지된, **수식어·완곡어와 결합된 과잉 명사화 표현**만.
